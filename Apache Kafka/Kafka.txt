==================
== apache kafka == 
==================
- message 
-----------
	A message is a piece of data that is sent to Kafka.
	It represents an event or piece of information that you want to store and process.
	A message is a record of data or an event that is sent to Kafka.

- producer 
------------
	A producer is an application or system that sends messages to Kafka.
	The producer decides which topic the message should be sent to.
	A producer is an application that sends messages to Kafka topics.

- topic 
----------
	A topic is a named category or stream where Kafka stores messages.
	You can think of a topic like a folder for a particular type of data.
	A topic is a named stream/category used to organize and store messages in Kafka.
	A topic is not the actual physical storage unit.
	A topic is divided into partitions, and partitions are where Kafka actually stores the messages.

- consumer
------------
	A consumer is an application that reads messages from Kafka.
	A consumer is an application that reads and processes messages from Kafka topics.
	A consumer does not normally remove the message from Kafka when it reads it.

- broker
	A broker is a Kafka server.
	Each broker can store partitions from different topics.
	A broker is a Kafka server that stores and serves messages.
	Its job is to:
		receive messages from producers
		store messages
		serve messages to consumers
		manage partitions
		participate in replication

- partition
-------------
	A partition is an ordered sequence of messages inside a Kafka topic.
	A topic can have one or many partitions.
	Partitions are extremely important because they allow Kafka to scale and process data in parallel.
	A partition is an ordered sequence of messages inside a Kafka topic that provides scalability and parallel processing.
	Messages inside the same partition are ordered.

- offset 
-----------
	An offset is a unique sequential number assigned to a message within a partition.
	The offset tells the consumer where a message is located in a partition.
	An offset is the position of a message within a Kafka partition.
	offset allows a consumer to remember its position.

Message:
	A record of data or an event sent to Kafka.

Producer:
	An application that sends messages to Kafka topics.

Topic:
	A named stream/category used to organize messages.

Consumer:
	An application that reads and processes messages from Kafka topics.

Broker:
	A Kafka server that stores and serves messages.

Partition:
	An ordered sequence of messages within a topic that enables scalability and parallel processing.

Offset:
	A sequential position number assigned to a message within a partition.
